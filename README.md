# Visualizing Housing Market Trends: An Analysis of Sale Prices and Features using Tableau

## Project Overview
This project presents an interactive analysis of housing market trends using Tableau. It visualizes sale prices and property features to identify patterns, trends, and insights that support better real estate decision-making.

## Objectives
- Analyze housing sale prices.
- Study the impact of property features on pricing.
- Create interactive dashboards.
- Generate meaningful business insights.

## Tools Used
- Tableau
- Microsoft Excel / CSV Dataset

## Features
- Interactive Dashboard
- Sale Price Analysis
- Property Feature Comparison
- Trend Analysis
- Data Visualization

## Project Outcome
The dashboard provides an intuitive visualization of housing market trends, enabling users to explore property prices and key influencing factors effectively.
